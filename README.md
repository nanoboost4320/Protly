# Protly

カロリーとタンパク質（PFC）を記録する食事管理WEBアプリです。

## 完成機能一覧

- 朝・昼・晩の食事記録
- 食品名の候補は「よく使う／一度入力したもの」。栄養は手入力
- 一度入力した食材は消さず保存（設定から編集可・直近順）
- ジョイランチ月間カレンダーPDFの登録 → 昼食ワンタップ追加
- カロリー・タンパク質の目標設定と過不足表示
- PFCバランスの自動計算
- 食品の編集・削除・食事間の移動
- 履歴（カレンダー + 食材一覧 + 過去日の編集）
- 週・月の統計（カロリー/タンパク質の差分）
- ブラウザへのデータ保存（localStorage）
- **エクスポート／インポート**（JSONバックアップ）
- **クラウド自動同期**（Supabase・任意設定）

## 使い方

```bash
# 初回のみ
npm install

# 開発サーバー起動
npm run dev
```

ブラウザで http://localhost:3000 を開いてください。

### おすすめの流れ

1. **設定** で目標カロリー・目標タンパク質を保存
2. **ホーム** で「+ 食品を追加」→ 自分の食材候補を選ぶか、新規は名前と栄養を手入力 → 量を調整 → 追加
3. **履歴** で過去の食事内容を確認
4. **統計** で週・月のマイナスカロリーなどを確認

## 栄養データの出典

栄養は自分で入力します。成分表データは入っていません。ごはん 220g の計算に使う数値だけ、出典を [`docs/NUTRITION_SOURCE.md`](docs/NUTRITION_SOURCE.md) に書いてあります。

ジョイランチ連携の手順は [`docs/JOY_LUNCH.md`](docs/JOY_LUNCH.md) を参照してください。

## バックアップ

設定画面から次が使えます。

1. **エクスポート** … JSONファイルをダウンロード（今すぐ使える）
2. **インポート** … バックアップファイルから復元
3. **クラウド保存** … Supabase 設定後に端末間同期（手順: `docs/CLOUD_SETUP.md`）

## 注意

- 普段のデータはブラウザの localStorage にあります
- サイトデータ削除で消えることがあるので、定期的なエクスポートをおすすめします
- 市販品などは手動入力し、次回以降は自分の候補から選べます
