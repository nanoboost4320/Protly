# ジョイランチ（月間カレンダー）の使い方

Protly では、ジョイランチの **月間お弁当カレンダーPDF** を登録し、該当日の昼食へワンタップ追加できます。

## 手順

1. 公式サイト（[おべんとうジョイランチ](http://www.joy-lunch.co.jp/)）から、その月のカレンダーPDFをダウンロードする  
   （例: 月間メニューの PDF）
2. Protly の **設定** → **ジョイランチ（月間カレンダー）**
3. 年・月を合わせ、PDFをアップロード
4. 読み取った献立名・カロリー・P・F を確認・修正して **保存**
5. **今日** または **履歴** でその日を開くと、「ジョイランチを昼食に追加」が出る

## 注意

- **無料**で動作します（外部の有料OCR/AIは使いません）
- **文字がコピーできるPDF**向けです。写真やスキャンだけのPDFは読み取れません
- 日付はPDFに印字された数字ではなく、**年月と曜日の列位置**から割り当てます（印字位置ずれ対策）
- 炭水化物（C）はPDFに無いことが多いため、追加時にカロリー・P・Fから自動計算します
- 読み取り結果は必ず一覧で確認してから保存してください
- データはバックアップ／クラウド同期にも含まれます

## データの出典について

カレンダー内容の著作権はジョイランチ側にあります。  
Protly はあなたが入手したPDFを個人の記録用に取り込む支援機能であり、PDFの再配布は行いません。
