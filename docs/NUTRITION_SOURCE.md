# 栄養データの出典について

Protly の食品名入力では、まず **自分が一度入力した食材／よく使う食材** を候補に出します（一度追加した食材は消さず残ります。追加画面のチップに出るのは「よく使う」のみ）。  
設定 →「よく使う食材」「一度入力した食材」の各画面から編集・削除できます（直近に使ったものが上）。  
文部科学省の成分表は、候補パネルの「成分表から探す」から必要なときだけ使います。

## 日本食品標準成分表（任意検索）

- **出典:** 日本食品標準成分表（八訂）増補2023年
- **公表元:** 文部科学省
- **取得元:** https://www.mext.go.jp/a_menu/syokuhinseibun/mext_00001.html

### 利用上の表示

文部科学省は、食品成分データの利用・二次利用（アプリケーション等を含む）を認めており、出典の明示を求めています。  
Protly では次の文言で出典を示します。

> 日本食品標準成分表（八訂）増補2023年から引用

成分表の検索結果・選択時にも、この出典を表示します。

### データの扱い

- Excel（第2章）から、Protly で使う項目だけを抽出し `data/mext-foods.json` に同梱しています
- 値は **可食部100gあたり** です
- 成分表に無い市販品名・ブランド名などは候補に出ないことがあります。その場合は手動入力か「よく使う食材」を使ってください

データ再生成手順は `scripts/build-mext-json.mjs` を参照してください。
